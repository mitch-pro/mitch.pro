Background

Tyler, who worked on mitch.pro and later started Tylerium.pro, describes himself there as a former co-owner of mitch.pro who was denied credit and mistreated. This page gives my side.

Tyler's role

Tyler was never a co-owner. He gave himself that title, and I never removed it. I later gave him more limited permissions because changes he shipped took the site down more than once and put user privacy at risk.

Contribution

Tyler's work, counting the Codex commits made under his account, is about 7% of all lines ever added to the repository and about 4% of the code in it today.

How it was measured

Lines added over the history come from git log --numstat and count every line ever added, including code later rewritten or deleted. Lines in the codebase today come from git blame on the current tree, which attributes each remaining line to the commit that last changed it. The current count excludes lockfiles, images, fonts and other non-code files. Both use the commit author names on the public repository, with "Tyler Thompson" and "Codex" counted as Tyler's.

Tylerium.pro

Tylerium.pro is a copy of mitch.pro with features missing. Mitch.pro is still maintained, and nothing about how it runs or handles your data has changed.
